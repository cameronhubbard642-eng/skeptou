Settings

Agora Repository

The agora repo holds all paper content, templates, and branch history. Create it (private) then configure the GitHub Actions secrets below.

gh repo create cameronhubbard642-eng/agora --private --clone

After creation, copy the four agora-workflows/*.yml files from modules/energeia/agora-workflows/ into the agora repo's .github/workflows/ and push.

Connect Local Daemon

The local daemon watches your agora worktrees for file changes and handles Scrivener project operations. Run the installer on your Mac, then paste your daemon token here to register it.

Secrets Reference

Required secrets for Cloudflare Pages + GitHub Actions:

  • AGORA_DISPATCH_PAT — GitHub classic PAT, repo scope, on agora repo
  • AGORA_REPO — owner/repo for agora (e.g. cameronhubbard642-eng/agora)
  • CLOUDFLARE_API_TOKEN — Pages deploy permission
  • CLOUDFLARE_ACCOUNT_ID — Cloudflare account ID
  • CF_ACCESS_AUD — Cloudflare Access audience tag (CF Pages secret)
  • ENERGEIA_ACTIONS — KV namespace binding name (CF Pages binding)
